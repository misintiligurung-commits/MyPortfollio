My Projects

Rock Paper Scissors Game

The Rock Paper Scissors Game is a simple console-based project developed using the C programming language. The game allows a player to choose Rock, Paper, or Scissors, while the computer randomly selects one option. The program compares both choices and displays whether the player wins, loses, or gets a draw. The project includes features such as playing the game, viewing scores, saving scores in a file, and exiting the program. Through this project, I learned about conditional statements, loops, functions, random numbers, and file handling in C. It also helped me improve my programming logic and problem-solving skills.

E-Commerce

The E-Commerce project is an online shopping platform designed to make buying and selling products easier. Users can browse products, view details, add items to a cart, and place orders online. The project focuses on providing a simple and user-friendly shopping experience while helping me understand concepts such as UI/UX design, product management, navigation, and online transactions.

Web Design

Responsive Web Design is a skill that helps create websites that work well on different devices, such as computers, tablets, and smartphones. It uses HTML and CSS techniques such as flexible layouts, Flexbox, Grid, and media queries to adjust the appearance of a webpage according to the screen size. Learning responsive web design helps me create websites that are easy to use, visually attractive, and accessible on different devices.

School Management

The School Management project is a web-based application that helps schools manage their administrative tasks efficiently. It includes features such as student registration, attendance tracking, grade management, and communication between teachers and parents. This project allowed me to learn about database management, web development, and user interface design. It also helped me understand how technology can streamline school operations and improve communication within the educational community.
